# o-ui

o-ui 是独立实现的 Xray 管理面板，启动命令与程序名均为 `o-ui`。本项目源码以 [GNU GPL-3.0](LICENSE) 授权（2026-10-19用户选定）。发布平台仅 `linux-amd64`（x86_64）与 `linux-arm64`（aarch64）；macOS 构建只用于本机开发测试，不作发布包。Xray核心与Geo数据不包含在仓库或内部包中，由用户在面板中从官方发布下载，适用其各自许可（MPL-2.0等）。第三方前端/Go依赖许可见内部包`THIRD-PARTY-NOTICES.md`与`licenses/`。

当前版本提供**管理员登录、SQLite、官方Xray版本管理、保存即生效（官方预检后重启Xray）、连接导出与订阅、累计流量/到期额度执行**，以及Linux服务器一键安装脚本（安装时自动安装Xray官方最新正式版并设为开机自启；见下节。真实systemd/ACME/BBR环境尚未实测）。界面和流程独立编写。四预设使用网页导出配置的官方26.7.28真实连接/双向计数、到期/额度停止转发已验，XHTTP-TLS启动失败恢复已验。已修复官方统计省略零值时误停核心的问题；保持统计开启的两种DoH模式已通过授权的本机正向验收。入站、客户端和Xray设置保存后立即预检并应用；预检或启动失败时保留原运行配置并在页面提示。

## 服务器一键安装（Linux amd64/arm64 + systemd）

适用：x86_64或aarch64、使用systemd的Linux（Debian/Ubuntu/RHEL系等），root权限，已有curl或wget、tar。申请证书另需openssl；HTTP-01验证需socat或python3（缺少时脚本询问后用apt/dnf/yum安装）。安装时由面板程序自动下载Xray官方最新正式版（不含预发布），按官方摘要校验后选中，不启动代理；断网或失败只警告，面板照常启动，可登录后在面板中安装。重新安装沿用已有核心选择。

**以下真实环境流程尚未实测**：systemd服务、acme.sh/Let's Encrypt申请与续期、BBR持久化与回退、UFW/firewalld放行均只在临时目录+命令桩中测试（见“验证范围”）。请先在可重装的测试机上试用，生产机（含已有x-ui等服务、80/443被占用的机器）不要直接运行。

### 1. 下载并运行

```sh
bash <(curl -fsSL https://raw.githubusercontent.com/tpxcer/o-ui/main/install.sh)
```

或先下载Release中的`install.sh`与`SHA256SUMS`，核对后再运行：

```sh
curl -fLO https://github.com/tpxcer/o-ui/releases/latest/download/install.sh
curl -fLO https://github.com/tpxcer/o-ui/releases/latest/download/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS && sudo bash install.sh
```

脚本按`uname -m`选择`o-ui-linux-amd64.tar.gz`或`o-ui-linux-arm64.tar.gz`，核对同一Release的`SHA256SUMS`、包内路径（拒绝绝对路径、`..`、链接）与包内清单、`PLATFORM`后才安装。清单与包来自同一发布处，只能发现损坏或替换不一致，不是发布者签名。离线机器可`sudo bash install.sh install --package ./o-ui-linux-amd64.tar.gz`（同目录有`SHA256SUMS`时一并核对）。

### 2. 安装问答（所有改动在问答结束后才执行）

1. **语言**：简体中文/English。安装提示、`o-ui`管理命令、面板服务日志及网页默认语言随之（网页里切换并保存的语言仍优先）。
2. **面板端口**：1024–65535，默认随机，占用时重选。
3. **访问路径**：默认随机18位（如`/AbC…/`），可自定义为单段字母数字`_-`，`/`表示根路径；登录地址为`https://域名或IP:端口/路径/`。
4. **管理员**：用户名默认随机10位，可改；密码可输入（6–72字节，不回显），直接回车则随机生成18位，**只在安装结束时显示一次**，不写入磁盘。管理员由安装器在面板首次启动前离线设置（`bin/o-ui -init-panel-admin`，密码经标准输入），因此公网上不存在可被抢先的网页初始化入口。
5. **面板证书**（只提供HTTPS）：
   - `1` 自动申请证书（推荐）：填写域名或公网IP。
     - 域名：选**HTTP-01**（申请和每次续期时80端口须空闲且公网可达；80被占用时脚本会拒绝该选项）或**Cloudflare DNS API**（令牌需Zone.DNS编辑权限，可填Zone ID；不占80端口）。
     - IP：Let's Encrypt的IP证书是约6天的短期证书，只能用HTTP-01，按3天续期。
     - 续期：自动（systemd定时器每6小时检查，续期后重启面板，代理短暂中断，核心按“退出时在运行则自动恢复”恢复）或手动（`o-ui cert renew`）。
   - `2` 使用本机已有证书：自动扫描`/etc/o-ui/tls`、`/root/cert/*/`、`/root/.acme.sh/*/`、`/etc/letsencrypt/live/*/`、`/etc/o-ui/acme/certs/*/`，只列出在有效期内、含SAN且证书与私钥配对的证书（显示名称、到期时间与路径），编号选择；证书含多个名称时再选面板用的域名。选中后复制到`/etc/o-ui/tls/`并写入面板，不会自动续期。找不到时改为自动申请。
   申请成功或选中已有证书后都会自动写入面板证书与固定HTTPS来源。证书失败时可重新选择方式重试；放弃则面板只听`127.0.0.1`（不开放HTTP），之后运行`o-ui`在“证书管理”配置。
6. **BBR**：显示当前队列/拥塞控制并检查内核（4.9+且有tcp_bbr）；同意后写入`/etc/sysctl.d/99-o-ui-bbr.conf`（`net.core.default_qdisc=fq`、`net.ipv4.tcp_congestion_control=bbr`），记录原值，`o-ui bbr off`回退。容器等无法生效时自动撤销。
7. **防火墙**：仅在检测到已启用的UFW/firewalld时询问是否放行面板端口这一条规则；不改其他规则，也不改80端口。云安全组需自行放行。

### 3. 首次登录

安装结束显示完整信息：访问地址（`https://域名或IP:端口/路径/`）、端口与路径、用户名、密码（仅随机生成时显示这一次）、证书类型/域名/到期时间、Xray版本、服务与开机自启状态、BBR和管理方式。用浏览器打开该HTTPS地址登录；非本机访问只接受该HTTPS来源，明文HTTP、其他Host和网页初始化均被拒绝。Xray已在安装时选中（失败时登录后在面板中安装），登录后直接创建入站。o-ui服务在安装结束前已设为开机自启并启动。

### 4. 管理命令

安装后直接运行`o-ui`进入中英双语编号菜单（参照OUI的菜单）：1 查看当前设置、2 修改端口、3 修改访问路径、4 重置用户名和密码、5 证书管理（申请/改用已有证书、立即续期、查看证书）、6–10 启动/停止/重启/状态/日志、11 更新、12 卸载、13 BBR、0 退出。修改端口、路径或重置管理员时会先停面板、离线写入再启动；改端口时同步服务单元，并询问移除旧端口、放行新端口的防火墙规则。子命令仍可直接使用：

```sh
o-ui info | port [端口] | path | reset-admin
o-ui status | start | stop | restart | log
o-ui update [--version v1.2.3]     # 升级程序，数据保留；新版本启动失败自动回退，上一版保留在/opt/o-ui.prev
o-ui cert                          # 重新申请证书或改用扫描到的已有证书
o-ui cert renew [--force]          # 手动续期
o-ui bbr status | on | off
o-ui uninstall                     # 移除程序与服务，保留/var/lib/o-ui与/etc/o-ui
o-ui uninstall --purge             # 输入DELETE后删除全部数据、证书与服务用户
```

### 5. 安装布局

| 路径 | 内容 | 属主/权限 |
| --- | --- | --- |
| `/opt/o-ui` | Release包（`o-ui`启动命令、`bin/o-ui`、`dist`、许可、`SHA256SUMS`） | root，只读 |
| `/var/lib/o-ui` | 面板数据库`panel/`与核心`core/` | 专用用户`o-ui`，0700 |
| `/etc/o-ui/o-ui.conf` | 语言、端口、证书方式等安装记录（不含密码或令牌） | root，0600 |
| `/etc/o-ui/tls` | 面板证书与私钥 | root:o-ui，目录0750/文件0640 |
| `/etc/o-ui/acme` | 固定版本acme.sh（3.1.6）及其账号/证书；Cloudflare令牌由acme.sh保存在`data/account.conf`供续期 | root，0700 |
| `/etc/systemd/system/o-ui.service` | `User=o-ui`、`Restart=on-failure`、`KillMode=mixed`（SIGTERM只给面板主进程，由面板停核心并保留自动恢复标记）；为调用防火墙助手不设`NoNewPrivileges`，`/etc/ufw`可写 | — |
| `o-ui-cert-renew.service/.timer` | 自动续期时才有 | — |
| `/usr/local/libexec/o-ui-firewall` | 入站端口防火墙助手：面板创建/删除入站时经sudo放行或撤销该端口（`allow\|delete 端口 tcp\|udp`），只删除自己记录过的规则 | root，0755 |
| `/etc/sudoers.d/o-ui` | 只允许`o-ui`以root运行上述助手（`visudo -c`校验后安装） | root，0440 |
| `/var/lib/o-ui-firewall/rules` | 助手放行过的规则记录；`uninstall --purge`时按此撤销 | root，0600 |

## 可选 HTTPS 管理与订阅访问

- “面板设置”参照OUI：顶部“保存/重启面板”，常规、安全、订阅三个标签，整页一个“保存”。常规页的面板监听IP（留空为全部IP，127.0.0.1为仅本机）、监听域名（对外访问时必填，须与证书一致）、端口、访问路径、会话时长与证书公钥/私钥路径一起保存（`PUT /api/panel/general`，单事务），因此改域名和换证书可一次完成；由仅本机改为对外访问时弹窗确认一次。监听、域名、端口、路径与证书在重启面板后生效，会话时长对之后的登录生效。
- 只支持直接监听1024–65535端口，来源端口须相同，不含路径、凭据或查询参数；不支持反代/端口映射，也不信任`X-Forwarded-*`绕过TLS、Host或Origin检查。非本机模式不允许HTTP，禁止远程初始化管理员；仅接受配置的Host，不继承Vite开发来源。
- 访问设置与证书均保存到现有SQLite文档；保存不改变本次启动，点“重启面板”后生效，页面分别显示已保存/已生效修订。手动重启后按日志中的地址访问；已有访问设置优先于`-listen`或启动脚本的初始端口。默认开发页5178不能代理已切HTTPS/固定来源的服务，应使用构建后的直接HTTPS页面。
- 证书不可读、失效、名称不匹配或访问设置损坏时拒绝启动，不退回默认HTTP。更换来源域名与证书时可先保存仅本机访问设置，再保存新证书和新的非本机设置，最后手动重启。面板本身不申请或续签证书，也没有免登录网络救援或网络配置工具；服务器安装器可用acme.sh申请/续期并重启面板加载（见上节）。可由状态目录拥有者停服后显式执行下述离线恢复命令；访问/证书设置不随业务备份迁移。

## 管理员修改密码

- 两步验证（TOTP，RFC 6238，6位/30秒）：在“面板设置→安全”打开“启用2FA”，服务器生成密钥并显示二维码与密钥，用验证器扫码后输入一次验证码才启用；之后登录页多一个验证码输入框，修改账号与停用2FA也需要验证码。验证码错误与密码错误共用5次/15分钟限速，同一时间步的验证码不能重复使用。丢失验证器时在服务器上运行`o-ui`菜单“重置用户名和密码”（离线重置会同时清除两步验证）。
- 登录后在“面板设置→安全”输入原密码，可只改用户名、只改密码或两者都改（已启用两步验证时还需验证码）；密码按UTF-8计6至72字节，不能与当前密码相同，成功后全部会话失效需重新登录。没有找回或免当前密码重设入口。
- 当前密码验证、新bcrypt哈希与所有旧登录失效在同一事务完成；失败不部分生效。错误密码与登录共用5次错误/15分钟的持久限速。成功后返回登录页，用新密码重新登录；不改变用户名、业务数据、节点身份、订阅或Xray进程。
- 密码输入不写入浏览器存储，失败或离开设置页清空；不记入诊断摘要。请求超时可能已提交，先尝试新密码登录确认，不要反复提交。已经认证并执行中的其它请求不会被追溯取消。

- 2026-10-19新增启动自动恢复后，macOS ARM64实际面板程序（race，官方26.7.28/26.3.27临时副本）已验：正常退出与父进程SIGKILL后自动恢复原身份真实连接、仍剔除到期/用尽用户且不夹带新草稿/另选版本；手动停止或服务端核心被单独杀死后再启动保持停止。随后内部包程序在macOS ARM64与全新无网Linux ARM64内存客体复验同一专项通过（见验收记录）；浏览器流程未就此重验。
- 此前实际面板程序正常退出及父进程SIGKILL后的显式恢复/原身份真实连接已在macOS ARM64和Linux x86_64隔离验证；此前本机浏览器已验证停止、历史预检不启动、勾选确认及实际恢复反馈。Linux ARM64另已验内存环境运行和专用ext4盘整客体中断后的XHTTP-TLS恢复，详见上述两份记录；不是实际硬件断电或本轮cmd/panel全矩阵。

## 创建与面板证书设置

- REALITY候选为AMD、Microsoft、Apple、Amazon、特斯拉（`www.tesla.com:443`）；只自动填写目标和SNI，不探测外站、不保证候选在服务器可用。默认仍为AMD，刷新轮换同步SNI。公私钥必需但无需手填：后端首次预检生成持久身份，私钥不显示，客户端导出公钥。换目标不会轮换密钥。
- 两种REALITY预设可单独开启“Mihomo兼容模式”，默认关闭并保留官方最低客户端策略；开启只把`minClientVer`设为`1.8.2`，保存草稿后另行应用才生效。Xray官方警告降低最低版本可能增加被识别、封锁风险；不关闭证书校验，仅本机测试，不自动修改VPS。
- 创建/编辑都可设置嗅探总开关、HTTP/TLS/QUIC、FakeDNS、仅元数据、仅路由，以及排除IP/域名。新建默认启用HTTP/TLS/QUIC/仅路由；FakeDNS/仅元数据默认关闭。排除每组最多64项，仅IP/CIDR、普通域名/domain:/full:，不加载外部Geo文件；跳过嗅探改写不等于阻断访问。FakeDNS需另外配置DNS；仅元数据不读取普通连接内容。
- “面板设置”填写本机PEM证书链及私钥绝对路径，验证配对/有效期后保存；不上传或返回私钥内容，不自动申请证书，不自动重启。设置保存在现有SQLite文档中，无新增SQL表结构。
- 方便时手动停止并重启**新面板**，再访问匹配证书的`https://127.0.0.1:5180/`或`https://localhost:5180/`（端口按启动参数）。首次自签证书需用户自行建立信任，不跳过验证。当前本机Host白名单不支持任意生产域名；Vite开发代理仍指向HTTP，启用HTTPS后使用构建后的后端页面，不继续使用5178开发代理。
- 保存与启动生效状态分开，源证书更新也需重启；启动时证书无效/丢失则拒绝启动，不静默降级HTTP。没有网页关闭HTTPS入口，可停服后在本机执行离线访问恢复；测试前仍应保留可用文件和数据库备份。
- HY2/XHTTP-TLS复用本次启动已加载的证书快照，空SNI自动使用首个非通配域名或IP，显式SNI须匹配；全通配证书必须手填具体域名。未生效可保存草稿，但活动TLS入站不能应用。停用或无有效客户端无需证书。
- 业务备份嵌入入站复用的证书，恢复为独立受限路径，不依赖目标面板启用HTTPS；面板HTTPS设置本身不备份，目标面板需另行设置。仅本机测试，旧OUI/VPS证书不会自动读取或导入。

### 证书或访问设置故障后的离线恢复

先正常停止新面板（同一状态目录仍被占用时命令会拒绝），使用已校验完整内部包中的程序：

```sh
/构建包的绝对路径/bin/o-ui -recover-panel-access \
  -state /新项目独立数据根/panel -listen 127.0.0.1:5180 \
  -confirm-recovery '恢复面板本机访问'
```

- `-state`须显式指定**已存在面板数据库所在目录**的绝对路径。内部包使用数据根下的`panel/`；源码默认是项目下`.runtime/panel`，不要填核心目录、数据根本身或旧OUI目录。不创建空库，不重置/找回管理员密码。
- 先在该状态目录生成`access-recovery-*/settings.json`（目录0700、文件0600），保存原访问/证书路径设置及修订，再同事务恢复回环非特权监听并停用面板HTTPS。备份仅含这两项设置，不含证书内容或账号；是私有明文维护副本，不是可导入的加密业务备份，不自动覆盖/清理。
- 账号与现有会话、草稿、节点身份、累计流量、订阅授权、已应用历史、核心包/所选版本保持；命令不启动面板或Xray、不绑定端口、不修改网络。失败时保留已生成副本，事务不部分提交；未确认完成时先检查数据库，勿把失败副本当有效回退点。
- 完成后手动正常启动新面板，从输出的`http://127.0.0.1:端口/`登录。浏览器的旧Secure Cookie或HSTS可能仍生效，必要时重新登录或使用干净的本机浏览器会话；恢复命令不清理浏览器策略，也不会把原公网HTTPS来源改为可远程HTTP访问。
- 原已应用TLS入站的受限证书快照不变，仍需明确恢复运行历史；如快照证书本身过期/损坏则继续拒绝。新草稿若复用面板证书，须重新配置有效面板HTTPS并重启后才能应用，不会自动借用旧证书。普通启动/脚本从不自动执行此恢复。

实际面板程序的HTTP保存→HTTPS重启、会话/草稿保持、登录退出、安全Cookie及证书缺失拒启动专项（编译临时程序、显式测试CA，不修改系统信任）：

```sh
PANEL_PROCESS_QA=1 go test -race ./internal/localapi -run '^TestPanelHTTPSProcessLifecycle$' -count=1 -timeout=3m
```

端口占用等监听失败会以非零状态退出，不将失败报告为正常结束；正常停止保持退出0，清理自有运行资源，不接管已有服务。真实进程冲突与HTTPS生命周期回归可一起运行：

```sh
PANEL_PROCESS_QA=1 go test -race ./internal/localapi -run '^TestPanel(ListenerConflict|HTTPSProcessLifecycle)$' -count=1 -timeout=3m
```

独立临时库的HTTPS浏览器夹具（不使用正式账号或`.runtime`，默认10分钟自动结束）：

```sh
PANEL_BROWSER_QA=1 PANEL_BROWSER_HTTPS_QA=1 go test -v ./internal/localapi -run '^TestBrowserFixture$' -count=1 -timeout=12m
```

使用输出的测试地址和临时证书路径；浏览器不信任自签证书时，由用户手动处理仅该测试页的例外，不自动绕过警告或导入系统信任。显式测试CA的接口通过不等于浏览器登录/保存流程已通过。夹具默认仍HTTP，HTTPS须显式开启。

在无开发工具的隔离Linux环境，可预先编译面板和localapi测试，再将`PANEL_PROCESS_QA_BINARY`指定为新建私有测试目录内的面板绝对路径，沿用上述测试。未设置时仍本机临时编译；此变量仅测试使用，不是产品配置或生产部署入口。

停用最后一个客户端后再次应用，会关闭旧监听并记录空配置修订，不会继续保留旧客户端访问；只保存停用草稿不等于已经切断连接。

启用客户端可设置到期及非零累计额度；流量统计常开（设置页不再提供关闭开关）。配置/证书/限制策略快照暂保留，不自动批量清理。本机订阅已接入，仍不能直接用于VPS。

## 真实流量与限制

- 通过官方所选核心的StatsService读取用户上下行，不清零核心计数器；仅启用StatsService，Unix套接字父目录0700，不开TCP管理端口或HandlerService。 统计Unix套接字目录（`/tmp/ixp-随机数字`）按面板进程创建，面板正常关闭时删除（2026-10-19修复此前每次重启遗留空目录）；面板被强杀时无法清理，可能遗留一个空目录。
- 约每2秒采样，将累计与实例基线作为一个SQLite文档事务保存。重复采样不重复累计，核心重启从新实例计数累加，正常停止/切换前再采样；客户端页显示准确十进制GB（1 GB=10亿字节）、最后采样、停止/过旧/失败状态。新客户端不重置其他用户用量，不自动按月清零。
- 限制仅依据已应用策略与配置快照，不夹带新草稿；到期或用尽时移除用户并重载，断开已有连接。没有有效用户则停止，不留旧监听。其他同核心用户会短暂重连；预检后再校验额度/到期，跨界则拒绝应用。
- 四预设已分别验证到期/额度执行。HY2在官方26.7.28关闭传输时不发送QUIC结束通知：服务端转发已停止，客户端仍可能显示连接中，直到默认约30秒空闲超时；这不表示仍能传输。专项分别检查10秒内上游关闭/接收停止、运行配置剔除受限用户及后续客户端感知，不承诺即时EOF。
- 这不是硬实时限流或精确计费：采样、预检及重载会有延迟/超额，采样到进程停止之间仍可能有少量尾流。断电、崩溃或采集故障时未采集尾流无法补算。关闭统计期间也不计量，历史缺口标记会保留，不用0冒充未知。
- 采集/保存/限制重载失败时安全停止独立核心并提示，已存累计不清空；账本损坏拒绝启动控制器。面板重启识别未正常停止检查点；仅支持上节的显式历史恢复，不搜索/接管已有孤儿核心。IP上限仍不支持。

隔离统计、到期/额度、重启及采集失败专项：

```sh
PANEL_RUNTIME_QA_CORE="$PWD/.runtime/core" go test -race ./internal/localapi -run '^TestOfficialTrafficLimits$' -count=1
```

## 客户端订阅

- 先编辑客户端开启“允许订阅”并保存，再从该客户端的“连接信息→客户端订阅”勾选确认，单独生成链接。使用当前HTTPS或本机HTTP页面来源，不接收任意路径或远程HTTP来源。不会自动创建或自动复制；生成/重置只返回一次完整地址，关闭、切页、隐藏标签或退出登录后清除显示。遗失需重置，状态接口不能取回原地址。
- 每客户端独立256位随机密钥，SQLite只保存SHA-256摘要；生成、重置、撤销仍需管理员同源确认及修订匹配。持有链接即可免登录读取该客户端的一个已应用节点，格式为“单条分享URI加换行”的标准Base64，不是多用户合集、Clash YAML或完整客户端配置。
- 读取要求自有核心正在运行、入站与设置修订和实际运行快照一致，客户端启用、订阅选项开启且未到期/未达已保存累计额度。未应用修改或核心停止时拒绝读取，不返回草稿身份；流量仍有采样延迟，不是硬实时计费。
- 重置使原订阅链接失效，撤销不回收已经下载的代理凭据或已有代理连接；要停止代理访问，需停用客户端并另行应用。保存关闭订阅选项或删除客户端时同事务撤销；重新开启或复用客户端ID不复活旧链接。
- 业务备份不包含订阅密钥或摘要，恢复时同事务使全部旧订阅链接失效，不会通过回退副本恢复授权。之后需逐客户端重新生成。
- 摘要记录最多5000个客户端ID，包含已失效记录，不自动批量清理；已存在ID可重置，新历史ID达到上限时拒绝生成。数据库损坏拒绝自动重置。
- 默认回环；显式非本机模式必须HTTPS及固定Host，仍拒绝跨来源读取，无缓存/跨域授权或重定向。Vite仅代理默认本机HTTP后端，代理失败日志脱敏地址。Mihomo固定版本原订阅文件导入已验；新增固定HTTPS来源免登录读取、重置/撤销与官方代理链路只在回环通过，手机跨设备、公网及GUI订阅流程未验。

- 首页布局：网速/四行资源仪表、服务器/套餐、Xray/面板、四组运行统计。
- 首页真实系统监控：独立约2秒采集CPU、非可用内存、交换空间、数据目录所在文件系统、系统负载/主机与运行时间。“整体速度”和“业务流量累计”只统计本面板客户端经Xray的流量（统计接口用户计数，约2秒一次），不读整块网卡；核心停止时速度为0。90点约3分钟历史只存内存。服务器套餐的月流量仍按网卡计数，以对应服务商账单。

## 业务备份和恢复

- 登录后从首页打开“备份和恢复”，设置独立备份密码并确认后下载`.ixpb`。AES-256-GCM认证加密，scrypt固定参数N=65536/r=8/p=1（约64 MiB派生内存），随机盐和nonce；密码12至256 UTF-8字节、不落盘。忘记密码无法恢复。包明文上限8 MiB，单个证书/私钥最多1 MiB，无压缩归档或包内任意落盘路径。
- 导出读取事务业务快照，运行时先保存最新流量检查点；未应用草稿缺少身份时首次导出会生成并持久保存身份，不启动代理。未填写证书的TLS草稿仍保持未完成状态；已有路径但文件缺失/不匹配则拒绝备份，不静默跳过。
- 仅包含workspace、xray-settings、proxy-identities、traffic与入站TLS证书/私钥。**不包含管理员账号/密码哈希、登录会话、登录限速、核心包/所选版本、运行历史、订阅密钥或摘要**。新安装先自行设置管理员并安装所需官方核心，再恢复。自定义设置引用的额外文件、Geo资源和外部服务不随包迁移，需要另行核对。
- 先停止当前控制器核心，选择文件/输入该备份密码，预览准确覆盖/移除的记录后勾选同意；未确认、任一文档修订或备份内容改变时拒绝提交。预览不写库；普通草稿API的逐项删除保护不放宽。
- 提交前在`-state`指定目录的`runtime/restore-*/`保存加密回退副本（文件名由页面显示，可另下载），**使用本次导入包相同密码**；证书只写新建0700目录内0600文件，原路径不覆盖。文件与目录同步成功后，单个SQLite事务CAS更新四个业务文档、清空本地运行历史并换代撤销全部旧订阅链接，修订递增；账号与会话保持，不启动代理。失败可能留下受限暂存文件，不自动批量清理。
- 恢复已有同ID累计时，上下行分别取当前与备份较大值，不回退额度用量、不简单相加；清除旧实例基线、保持停止并标记未知历史缺口。新安装只知道备份时用量，之后未知尾流无法补算，非精确计费/精确时间点数据库回滚。
- 回退副本通过同一预览/确认流程恢复，流量仍不减少；关闭成功弹窗重新加载，再核对设置、端口、证书有效期并官方预检/应用。服务断线/超时不代表服务器一定未提交，应重新登录核对后再操作。
